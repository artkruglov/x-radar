# X-радар · Вымышленный выпуск

Все компании, события и утверждения ниже придуманы. Это образец структуры, не новости.

## STORY

- Logline: проверяем границы действий агента на вымышленных историях.
- One sentence: у каждого внешнего действия есть точка решения.
- Hero: читатель.
- Stakes: цена ошибки.
- Turn: от скорости к проверяемости.

**Голос:** «Это вымышленный выпуск для проверки шаблона. Покажем четыре изменения и один следующий шаг.»
