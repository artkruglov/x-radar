# Оформление выпуска

Шаблон показывает восемь карточек: хук, четыре новости, молнию, заметки и финал. Вертикальный размер — 1080×1920. Горизонтальная композиция показывает ту же карточку по центру.

- Бренд и подпись: `brand.json` в папке выпуска (создаётся из `brand.example.json`).
- Цвета: `src/film/theme.ts`; доступны lime, coral и terminal.
- Сцены и текст: `src/film/News.tsx`; используйте тайминг голоса из `cues.ts`.
- Шрифты по умолчанию — системные; внешние файлы шрифтов в репозиторий не входят.
- Изображения необязательны. Для собственного фона оставляйте верхнюю треть спокойной, без текста и логотипов; заголовки накладывайте кодом.
- Проверьте по кадру каждой сцены и готовое видео. Заголовки, подписи и субтитры должны помещаться без пересечений.

`genimg.py` — дополнительный адаптер внешнего провайдера. Его модель задаётся через `XRADAR_IMAGE_MODEL` или `--model`. Доступность и стоимость при публикации репозитория не проверялись.
