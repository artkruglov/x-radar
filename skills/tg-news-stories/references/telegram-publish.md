# Публикация в Telegram через браузер (Telegram Web A)

Публикуйте только после явного «да» пользователя на каждый выпуск. Не трогайте другие чаты. Удалять сообщения нельзя — попросите пользователя.

Работайте в **новой вкладке**: пользователь может сидеть в Telegram в своей. Канал: `https://web.telegram.org/a/#<channel-id>`.

## Видео
1. Перед вставкой очистите поле ввода канала (`#editable-message-text`): если там черновик, он станет подписью к видео или его кто-то отправит.
2. Вставьте скрытый `<input type=file id=claude-upload aria-label=claude-upload-input>` в `document.body`, найдите его через `find`, загрузите mp4 через `file_upload` (лимит инструмента — 10 МБ, поэтому `scripts/tg_mux.sh`).
3. JS: `ClipboardEvent('paste')` с файлом из `claude-upload.files[0]` в `#editable-message-text` → откроется окно Send Video.
4. Подпись: `ClipboardEvent('paste')` с `text/html` в `#editable-message-text-modal`.
5. Скриншот → кнопка отправки в окне (синяя справа внизу).

## Текстовый пост
1. Вставьте HTML поста (`text/html` + `text/plain`) в `#editable-message-text`. `<blockquote expandable>` сохраняется как сворачиваемая цитата.
2. Уберите превью ссылки (крестик справа над полем), иначе под постом будет картинка первой ссылки.
3. Отправьте. Проверьте последние сообщения через JS (`.Message .text-content`).

Порядок: сначала видео, потом пост («подробности ниже»). Если пост ушёл первым — в подписи к видео напишите «в посте выше».

## Заменить видео в опубликованном посте
Правый клик по видео → Edit → вставьте новый файл в `#editable-message-text` (появится окно Replace Video, подпись сохранится) → Save.
