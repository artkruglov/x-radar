# Проверка публичной версии

Дата: 27 октября 2026. Проверка выполнена на macOS; Python 3.14.6, Node и локальный Chrome. Для ядра используются только стандартная библиотека Python и вымышленные данные.

## Выполнено

- Восемь интеграционных тестов: JSONL/массив, дедупликация, одновременный приём, отказ на повреждённом входе без изменения базы, декодирование экспорта, текущий/предыдущий период, пустая база, разметка и фильтр списков.
- Искусственная DOM-страница: collector/export, счётчики, Unicode и отказ при отсутствующем списке. Без сети и аккаунта X.
- Демонстрационные команды README: первый приём `new=8`, повторный `new=0 dup=8`; фактпак — семь постов текущего периода и один предыдущего; по одному посту на каждый редакционный трек.
- Обёртка `pull.sh` приняла base64 со stdin; повторные посты остались дублями.
- Синтаксис двадцати Python-файлов и шести Bash-файлов.
- Установка npm-зависимостей нового видеопроекта и проверка `tsc --noEmit`.
- Линтер вымышленного сценария: ошибок нет; остались ожидаемые предупреждения об интонации, паузах и числах. Извлечены девятнадцать реплик.
- Remotion: восемь кадров вертикального шаблона через локальный Chrome, по одному на каждую сцену; кадры просмотрены. В блоке молнии уменьшен текст, чтобы освободить место субтитрам.
- Проверка запрещённых имён, реальных id исходных списков, аккаунта-читателя и личных путей: совпадений нет.
- Поиск по заданным словам: совпадения только с именем переменной окружения внешнего провайдера и её документацией. Значений ключей нет.
- Gitleaks 8.30.1: проверка файлов и истории исходного коммита — утечек нет. Реальные настройки, база и медиа исключены из Git.

## Не проверялось

- Живой сбор с текущих страниц X, полнота ленты, локализованные метрики, вход и расписание в среде пользователя.
- Внешние модели: авторазметка, TTS, транскрипция, генерация изображений/музыки. Идентификаторы в исходном видеопайплайне исторические и могут потребовать замены через переменные окружения.
- Полный рендер ролика с настоящей озвучкой, сведение звука, сжатие итогового видео, загрузка и отправка в Telegram.
- Актуальные должности и принадлежность аккаунтов из PEOPLE.md: это исторический снимок исходных гайдов.
- Linux и Windows. Ядро использует Unix-блокировку файла; на Windows потребуется адаптация.

Промпты расписаний — обезличенная адаптация исходного процесса. Внешняя отправка и установка расписаний не выполнялись.
