# Как участвовать

Опишите проблему, шаги воспроизведения и ожидаемое поведение. Для примеров используйте только вымышленные посты и аккаунты. В PR укажите изменение, проверку и ограничения.

Перед PR:

```bash
python3 -m unittest discover -s tests -v
node tests/collector.cjs
gitleaks detect --source . --redact
git status --short
git diff --cached
```

Новые пути и имена каналов задавайте в настройках; номера реальных списков не включайте. Не добавляйте базу, приватные метки, логи, настройки аккаунтов, реальные выпуски или медиа. Сохраняйте MIT notices сторонних компонентов. Публикуемые фикстуры должны оставаться полностью вымышленными.

Для изменения DOM-сборщика приложите обезличенный минимальный пример разметки. Работа на искусственной странице не заменяет ручную проверку в X. Для изменения видео нужны кадры всех сцен и просмотр звука; не делайте платные внешние вызовы в автоматических тестах.
